# Coding Schedule (12 months)

Same rules as SQL coding:
- Months 1–9: Mastery (topic depth, clean Java solutions, questions in comments)
- Months 10–11: Competition (timed / contest-style)
- Month 12: Interview (speak approach, follow-ups, mock rounds)

## Daily habit (coding slice)

1. Read the day's problem(s) from comments in the `.java` file (when present).
2. Solve yourself first.
3. Compare with the correct final solution in the same file.
4. Note pattern + edge cases; no separate attempt files.

## Platforms (competition months)

- LeetCode, Codeforces, AtCoder, HackerRank — pick one primary per week during Months 10–11.
