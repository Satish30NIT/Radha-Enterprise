# SQL Coding — 6-Month Schedule (Zero → Advanced)

**Path:** `sql-coding/month-0N-topic-wise/day-XX-concept/`  
**Daily habit:** 1 SQL topic (~20 min) beside Java day  
**Style:** correct final `.sql` only · questions in comments · experienced depth when notes are added

| Month | Theme | Outcome |
|---|---|---|
| **01** | Foundations + joins start + pagination | Write solid SELECT/JOIN/GROUP queries |
| **02** | Joins/subqueries deep + OMS practice | Confident multi-table + reporting SQL |
| **03** | Indexes, EXPLAIN, transactions, locking | Reason about performance & correctness |
| **04** | Windows, CTEs, analytics | Build real dashboard-style queries |
| **05** | PostgreSQL + Radha schema | Design/query tenant-safe OMS schema |
| **06** | Interview drills + complex OMS SQL | Explain & solve under time pressure |

---

## Month 01 — Foundations → first mastery
`sql-coding/month-01-topic-wise/`

Basics → WHERE/NULL/LIKE → aggregates → joins → subqueries → functions → indexes intro → transactions intro → pagination → OMS practice → review

## Month 02 — Join/subquery depth + OMS SQL
`sql-coding/month-02-topic-wise/`

- Join recap, anti/semi joins, subquery styles  
- CASE, functions deep  
- Radha-shaped practice: orders, inventory, payments, reports  

---

## Month 03 — Performance & transactions
`sql-coding/month-03-topic-wise/`

- Indexes (btree/composite/covering) + EXPLAIN/ANALYZE  
- ACID, isolation, locks, deadlocks, `FOR UPDATE`  
- N+1 at SQL, batch/upsert, soft-delete, slow-query checklist  

---

## Month 04 — Analytics SQL
`sql-coding/month-04-topic-wise/`

- Window functions (ROW_NUMBER, RANK, LAG/LEAD, running totals)  
- CTEs / recursive CTE  
- Top-N-per-group, funnels, OMS GMV/channel/tax analytics  

---

## Month 05 — PostgreSQL + Radha schema
`sql-coding/month-05-topic-wise/`

- PG types, JSONB, constraints  
- Schema design: tenancy, membership, catalog, orders, payments, tax  
- Partial indexes, safe migrations, inventory concurrency, outbox idea  

---

## Month 06 — Interview + capstone
`sql-coding/month-06-topic-wise/`

- Timed interview sets (joins/windows/transactions)  
- Classic patterns (2nd highest, duplicates, manager tree)  
- Complex OMS SQL + “explain your query aloud”  
- Capstone: Radha dashboard SQL + final review  

---

## Rule of progress
1. One day folder = one concept  
2. Don’t skip Month 03 before calling yourself “strong at SQL”  
3. Month 05–06 must connect to **Radha Enterprise** tables/decisions  
4. Interview pack is Month 06 + Month 2 Java revision synergy — not every random day  

**Total:** 6 × 30 = **180 focused SQL days**
