# Coding (DSA) — 10-Month Plan

Same shape as `sql-coding/`.

## Intent

| Phase | Months | Goal |
|---|---|---|
| **Mastery** | **1–6** | Coding skill to strong backend-interview / problem-solving depth |
| **Competition** | **7–8** | Online coding competition practice |
| **Interview** | **9–10** | Coding interview questions + mocks |

**Path:** `coding/month-NN-<topic>/day-XX-concept/`
